# 対応状況と残っている機能

2026-10-31。コード、Apple / Googleの公式Webクライアントと利用ガイド、実機・模擬データの検証を照合しています。「画面がある」「暗号関数が動く」だけで、実サービスとの接続成功とは扱いません。

## 3.3.0-rc1で追加した機能

| 機能 | 3.2.0-rc2まで | 今回の実装と検証範囲 |
| --- | --- | --- |
| Googleのサウンド再生・停止 | 無効 | サービスが操作可能と返す端末だけに表示。ネイティブ確認後、同じGoogleセッションの対象を照合して1回だけ操作。模擬ページで検証し、実際の発音は行わない |
| Googleの紛失モード | 未対応 | 連絡先・80文字までのメッセージをネイティブで入力・再確認。公式ページの対象とアカウントを再照合して送信。同一ページ内のPIN等は本人が公式画面で操作。再認証の別ページへの移動を伴う端末では操作を中止する。実機への送信は未検証 |
| Appleの「見つかったときに通知」 | 未対応 | AppleがNWF / LKLの両方を返す端末に設定を表示。`saveLocFoundPref` の対象別の返却値で保存を確認。模擬応答による検証のみ |
| Googleの暗号化された位置の追加確認 | 接続開始へ戻る | 端末の詳細から対象の公式PIN確認へ進める。パスワード・PINの入力や保存をアプリで自動化しない。実際のオフライン復号は未検証 |
| 端末0台のGoogleアカウント | 完了条件が1台以上 | 本人確認済みのアカウントで明示的な空一覧が返った場合は空一覧として終了する。実ユーザーの空アカウントでは未確認 |
| 端末1台だけの更新 | 他の端末の位置が消える場合がある | 個別更新の対象以外の既存データを維持する。アカウント変更時は破棄する |

Google操作は、確認したアカウント・端末番号・元の端末名から計算する識別子を照合します。確認前の自動操作、再読み込み後の自動再送、別アカウントへの送信はしません。画面を離れた操作は中止し、結果が不明な場合は不明として表示します。端末やGoogleの画面変更、追加認証によって操作できない場合があります。

## 残っている範囲

| 機能 | 状態・不足している条件 |
| --- | --- |
| Appleの人の自動取得・位置共有 | 未対応。現在のデバイス用Webセッションでは、人の共有情報・接続経路を確認できていない。家族の端末位置を人の位置に代用しない |
| AirTagなどAppleの持ち物の自動取得 | 未対応。端末用APIと異なる所有者データ・鍵・サービスとの接続が必要。選択したファイル／連携元からの表示は対応済み |
| Apple Pencil Proの自動取得・近距離探索 | 未対応。追加連携からの表示のみ。Appleの機能一覧では位置・近くを探すはiPad向けで、Androidだけでの取得経路は未確認 |
| iPhone 17とのUWB探索 | 暗号処理の移植とGalaxyの能力取得まで。所有者トークンの正規取得、BLEでの対象識別と開始、NBAMMSとAndroid無線設定の対応、双方の実測が不足。iPhone側のアプリ導入や国コード変更は前提にしない |
| Appleの紛失モード解除・内容変更 | 未対応。停止関連の返却フィールドは確認したが、現行Webクライアントで必要な認証付き操作経路を特定できていない。未確認の解除要求を組み立てない |
| Googleの紛失モード解除 | 未対応。端末のロック解除と「見つかった」への状態変更は異なる。本人確認と正しいサービス操作の追加が必要 |
| 端末の消去・消去取り消し・アカウントから削除 | 未対応。Appleは追加のユーザー認証トークン等が必要。Googleも再認証を含む操作の実装が必要。今回のテストはこれらの操作を送信しない |
| Appleのサウンド停止・AirPodsの左右選択 | 未対応。Appleのチャンネル・安全確認・停止状態に応じた操作が必要。現在のAppleサウンドは端末全体への再生要求のみ |
| このAndroidをApple Find Myへ登録 | 未対応。通常のAppleログインやUWB搭載だけでは登録できない |
| このAndroid自身のGPS表示・位置共有 | 未対応。現在の地図は接続先サービスから返った位置を使い、端末のGPSやバックグラウンド位置を収集していない |
| オフライン地図・Apple Maps | 未対応。MapLibreの地図と地理院の航空写真をオンラインで取得する |
| Googleのアクセサリー・タグの分類と追加操作 | 実機未検証。現在はサービスのカタログを端末一覧へ表示し、取得できた公式画像を使う |
| 複数のApple / Googleアカウントの同時接続 | 各サービス1アカウント。切り替えは対応済みだが、同時接続用のプロファイル分離と一覧管理は未実装 |
| Google Playでの配信 | 未実施。GitHubの署名付きAPKで配布する |
