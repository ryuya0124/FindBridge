# Find Bridge

AndroidからAppleデバイスの位置を確認する非公式アプリです。Google Find HubのAndroid端末を同じ地図へ表示する試験的な接続も追加しています。地図・一覧・詳細・タブはKotlinのネイティブUIで、認証には各社の公式画面を使います。

## インストール

[非公開GitHubのプレビュー版](https://github.com/ryuya0124/FindBridge/releases/tag/v3.2.0-rc1)から `FindBridge-3.2.0-rc1-arm64-release.apk` をダウンロードしてインストールしてください。リポジトリへのアクセス権が必要です。

3.2.0-rc1ではダークモードの選択タブを見やすくし、ガラス背景の追従と画像取り込みを改善しました。Galaxy S26 Ultraの署名済みリリース版で、キーボード表示・認証の中断・再接続を含むAppleログインを確認しています。Google接続は試験段階です。

- Android 9以降のarm64端末に対応。Android 17 / API 37を対象にしています。
- 3.0.0から専用のリリース鍵で署名しています。以前のdebug版を使っている場合は、一度アンインストールしてから入れ直してください。Apple Accountへの再接続が必要です。
- 今後の同じ鍵によるリリース版は、データを保ったまま更新できます。

## 使い方

1. 「デバイス」からApple Accountに接続します。ネイティブの入力画面でメールアドレスとパスワードを入力します。「この端末に保存」「自動ログイン」を選べます。
2. 一覧のデバイスをタップすると、地図と詳細を確認できます。家族の情報が返るアカウントでは、メンバーごとに表示します。
3. 一覧の上端をドラッグすると高さを変更できます。右上の位置矢印ボタンで、位置のあるデバイスを地図に収めます。
4. 地図右上の設定から「標準」「航空写真」「航空写真＋地名」を切り替えられます。「自分」→「外観と地図」からも設定できます。
5. 外観はシステム連動・ライト・ダークに対応。ガラスの透明感も調整できます。「動きを減らす」でアニメーションを抑えられます。
6. 「自分」→「外観と地図」→「言語」から日本語・英語・簡体字・繁体字・韓国語・スペイン語・フランス語・ドイツ語を選べます。初期設定は端末に従います。

Googleを追加する場合は「自分」→「Googleアカウントに接続」を開き、Googleの公式画面でログインしてください。端末名・取得できた位置・電池残量をAppleデバイスと同じネイティブの一覧に表示します。GoogleのパスワードをApple用の入力画面へ入れる必要はありません。Google接続の実アカウントでの一連の動作と、オフライン位置の追加認証は未確認です。

Appleは表示中に30秒ごと、Googleは2分以上経過した際に更新します。画面を離れると更新を止めます。古い位置は元の取得時刻を表示し、位置が取得できないデバイスに架空の座標を割り当てることはありません。セッションは端末内に暗号化して維持します。保存と自動ログインが有効なら、起動・復帰時にセッションが切れている場合に再認証します。自動認証中はネイティブの「ログイン中…」を表示し、確認コードなどの追加確認が必要な場合だけ公式画面を開きます。キャンセルや認証失敗で自動ログインを一時停止したら、「自分」から再接続できます。

## 対応範囲

| 機能 | 現在の状態 |
| --- | --- |
| iPhone・iPad・Macなど | Appleのデバイス用サービスから取得。実アカウントで確認済み |
| Androidのデバイス | Google Find Hubとの試験的な接続。公式ログイン画面とデータ変換は実装済み。アプリ内の実アカウントでの取得は未確認 |
| 家族のデバイス | Appleが返すメンバー情報と所有者を照合して表示。公開される位置・状態の範囲に依存 |
| ダークモード・航空写真・ガラスUI | 対応。ばねの動き、タブの移動、シートのドラッグ、押下・地図ピンのアニメーション |
| タブレット・折りたたみ | 幅・向き・ヒンジに応じたサイドバー／縦タブ／上下ペイン。開閉時の選択を維持 |
| 多言語 | 8言語。地図の地名は提供元に訳がある範囲で追従 |
| 人・AirTagなどの持ち物 | ネイティブ一覧・詳細・地図と、追加連携データの読み込みに対応。Appleからの自動取得は未対応 |
| Apple Pencil Pro | 追加連携元がPencilのデータを返した場合に「デバイス」へ表示。実機データでの取得は未確認 |
| サウンド | Appleの対応デバイスで確認ダイアログ後に送信。実際の発音テストは未実施。Google・追加連携・Pencilでは無効 |
| UWBの距離・方向探索 | 未対応。GalaxyのUWB搭載は確認済み。Android単体で標準の「探す」へ接続する手順は未確認 |
| 紛失モード・ロック・消去 | 未実装 |
| このAndroidをFind Myネットワークへ登録 | 未対応 |

「人を探す」「持ち物」では、所有者が選んだ対応形式の位置データファイルを読み込めます。Apple Accountへのログインだけでこれらが自動取得される機能は、まだ実装できていません。対応する連携サーバー向けの接続ファイルにも対応しますが、サーバーやMacの常駐ソフトは同梱していません。形式は開発者向け資料に記載しています。

Apple Pencil ProはiPadだけでなく、iPhoneの「探す」でも探せるとAppleが案内しています。このアプリで近距離探索を再現する機能はありません。[Appleの説明](https://support.apple.com/en-gb/guide/ipad/ipad445ff36d/ipados)

地図はMapLibreとOpenStreetMap、航空写真は国土地理院の地理院タイルを使用します。国内の高解像度写真と、国外を含む低倍率の衛星画像で提供範囲が異なります。Apple Mapsではありません。[写真の提供範囲と出典](https://maps.gsi.go.jp/development/ichiran.html)

## データの扱い

広告・解析SDK・アプリ独自の中継サーバーはありません。保存を選んだメールアドレス・パスワードは、Android Keystoreの端末専用AES-256-GCM鍵で暗号化し、アプリ専用領域に保存します。確認コードは保存しません。認証済みセッションと追加連携設定は別々の鍵で暗号化します。バックアップと端末間転送は無効です。

保存をオフにして接続すると、既存の保存情報も削除します。「自分」→「ログイン情報」から保存情報を削除でき、サインアウトでも保存した認証情報を削除します。保存パスワードを画面に再表示せず、入力画面と自動認証画面のスクリーンショットは無効です。自動ログインはフォアグラウンド時のみ行い、再試行には5分の間隔を設けています。Apple側の追加確認やサービス変更により手動操作が必要になる場合があります。

Googleの認証状態は、Appleとは別のプロセス・WebViewプロファイルに保持します。Googleのパスワード・確認コード・復号鍵をアプリのデータモデルへ渡す処理はありません。GoogleのCookieはAndroidのアプリ専用領域に保存され、Keystoreで暗号化するAppleの保存パスワードとは保存方式が異なります。「Googleアカウントの接続を解除」でGoogle側のローカルCookieと接続情報を消去できます。

ネイティブ画面の位置データとガラス描画用の地図画像はメモリ内で扱います。Googleのサイト自身がWebViewプロファイルに保持するデータはGoogleの実装に依存します。追加連携で選択したファイルの管理は、そのファイルの所有者が行ってください。地図の表示範囲は地図提供元へ、Appleの更新要求はAppleへ、Googleの更新要求はGoogleへ送信されます。

Apple・Googleとは提携していません。各社のサービス変更によって使えなくなる場合があります。
