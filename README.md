# Find Bridge

AndroidからAppleデバイスの位置を確認する非公式アプリです。地図・一覧・詳細・タブはKotlinのネイティブUIです。Apple認証には公式画面を使い、Googleの接続開始にはGoogle Play開発者サービス（GMS）を使います。Google Find HubのAndroidデバイスも同じネイティブ画面に表示します。

## インストール

[GitHubのプレビュー版](https://github.com/ryuya0124/FindBridge/releases/tag/v3.3.0-rc5)から `FindBridge-3.3.0-rc5-arm64-release.apk` をダウンロードしてインストールできます。

3.3.0-rc5では、「背景のぼかし」の調整を従来のガラスの見え方に戻しました。設定名はそのままに、ガラスの透明感や縁の屈折を調整できます。

- Android 9以降のarm64端末に対応。Android 17 / API 37を対象にしています。
- 3.0.0から専用のリリース鍵で署名しています。以前のdebug版を使っている場合は、一度アンインストールしてから入れ直してください。Apple Accountへの再接続が必要です。
- 今後の同じ鍵によるリリース版は、データを保ったまま更新できます。

## 使い方

1. 「デバイス」からApple Accountに接続します。ネイティブの入力画面でメールアドレスとパスワードを入力します。「この端末に保存」「自動ログイン」を選べます。
2. 一覧のデバイスをタップすると、地図と詳細を確認できます。家族の情報が返るアカウントでは、メンバーごとに表示します。
3. 地図上で近い端末は台数付きのマーカーにまとまり、タップするとその場所の端末を個別に選べます。一覧の上端をドラッグすると高さを変更できます。右上の位置矢印ボタンで、位置のあるデバイスを地図に収めます。
4. 地図右上の設定から「標準」「航空写真」「航空写真＋地名」を切り替えられます。「自分」→「外観と地図」からも設定できます。
5. 外観はシステム連動・ライト・ダークに対応。「背景のぼかし」で、パネル越しの地図の見え方を調整できます。外観・言語のメニューを閉じたり選択したりしても設定画面に戻れます。「動きを減らす」でアニメーションを抑えられます。
6. 「自分」→「外観と地図」→「言語」から日本語・英語・簡体字・繁体字・韓国語・スペイン語・フランス語・ドイツ語を選べます。初期設定は端末に従います。

Google接続は「自分」→「Googleアカウントに接続」から開始します。最初にGMSで端末のアカウントを確認し、完了後に「Find Hubへ接続」を押します。Googleへログイン済みの場合は、アカウント選択を繰り返さずFind Hubへの接続から進めます。追加確認が必要な場合だけ、アプリ内にGoogleの公式画面を表示します。パスワード・2段階認証・PIN・同意操作は本人が行ってください。Googleのパスワードを独自の入力フォームへ入れたり、Appleの保存パスワードをGoogleへ渡したりしません。端末一覧が実際に取得できた時点でネイティブ画面へ戻ります。実機で端末一覧・位置と、保存済みセッションからの再取得を確認しています。Googleが公開する範囲で表示し、位置が返らない端末に座標を作りません。

Google接続にはGMSと最新のAndroid System WebView / Chromeが必要です。アプリ内に開発者のメールアドレスや利用者の許可リストはありません。Find Hubで使う自分のGoogleアカウントを選んでください。端末が0台の一覧も読み込みを完了できます。現在はGoogleアカウント1つを接続でき、変更する場合は「Googleアカウントの接続を解除」から切り替えます。会社・学校・保護対象のアカウントは管理者やGoogle側の制限で利用できない場合があります。接続方法とエラーの対処は[配布・Googleログイン](docs/DISTRIBUTION.md)に記載しています。

端末画像は、Google Find Hubが端末カードに表示する画像と、Apple公式サービスの機種・色に対応した画像を取得し、一覧・詳細・地図ピンに使用します。Google端末へiPhoneの画像を流用しません。画像は必要なときに読み込み、APKには同梱しません。

紛失モードは対応するApple・Google端末の詳細から開きます。連絡先・メッセージを入力し、対象と内容を確認してから送信します。Appleの機種によっては新しいロックコードの設定が必要です。Googleで追加の本人確認が必要な場合は、公式画面で操作してください。Googleの別ページでの再認証が必要な操作は中止するため、端末によって利用できない場合があります。入力を中断しても送信せず、ロックコードや連絡メッセージを保存しません。アプリからの紛失モード解除は未対応です。

Appleは表示中に30秒ごとに更新します。画面を離れると更新を止めます。古い位置は元の取得時刻を表示し、位置が取得できないデバイスに架空の座標を割り当てることはありません。セッションは端末内に暗号化して維持します。自動認証中はネイティブの「ログイン中…」を表示し、確認コードなどの追加確認が必要な場合だけ公式画面を開きます。キャンセルや認証失敗で自動ログインを一時停止したら、「自分」から再接続できます。

## 対応範囲

| 機能 | 現在の状態 |
| --- | --- |
| iPhone・iPad・Macなど | Appleのデバイス用サービスから取得。実アカウントで確認済み |
| Androidのデバイス | GMS認証と公式Find Hubセッションを使用。実機で4台の一覧・3台の位置・保存済みセッションからの再取得を確認 |
| 家族のデバイス | Appleが返すメンバー情報と所有者を照合して表示。公開される位置・状態の範囲に依存 |
| ダークモード・航空写真・ガラスUI | 対応。ばねの動き、タブの移動、シートのドラッグ、押下・地図ピンのアニメーション |
| タブレット・折りたたみ | 幅・向き・ヒンジに応じたサイドバー／縦タブ／上下ペイン。開閉時の選択を維持 |
| 多言語 | 8言語。地図の地名は提供元に訳がある範囲で追従 |
| 人・AirTagなどの持ち物 | ネイティブ一覧・詳細・地図と、追加連携データの読み込みに対応。Appleからの自動取得は未対応 |
| Apple Pencil Pro | 追加連携元がPencilのデータを返した場合に「デバイス」へ表示。実機データでの取得は未確認 |
| サウンド | Appleの再生、Googleの再生・停止に対応。確認後に送信。実際の発音テストは未実施。Googleは試験提供、追加連携・Pencilでは無効 |
| UWBの距離・方向探索 | 未対応。GalaxyのUWB能力と暗号処理を検証済み。iPhone 17との接続・実測は未実装 |
| 紛失モード | Apple・Googleの対応端末で連絡先入力→内容確認→明示送信。Googleは試験提供。実端末のロックは未検証。解除は未対応 |
| 見つかったときに通知 | Appleの対応端末で設定可能。Apple Accountのメールアドレスへの通知。実サービスでの通知受信は未確認 |
| GoogleのPIN確認 | 詳細から対象の公式確認画面へ進む導線を追加。実際のオフライン位置の復号は未確認 |
| 端末情報 | 機種名・IMEI・MEID・初回登録日・OS・回線・充電など、サービスが返す項目のみ表示 |
| 消去 | 未実装 |
| このAndroidをFind Myネットワークへ登録 | 未対応 |

未対応・一部対応の詳しい一覧と、対応できていない理由は[対応状況](docs/FEATURES.md)にまとめています。

「人を探す」「持ち物」では、所有者が選んだ対応形式の位置データファイルを読み込めます。Apple Accountへのログインだけでこれらが自動取得される機能は、まだ実装できていません。対応する連携サーバー向けの接続ファイルにも対応しますが、サーバーやMacの常駐ソフトは同梱していません。形式は開発者向け資料に記載しています。

Appleの現在の機能一覧では、Apple Pencil Proの位置表示と「近くを探す」はiPadのみの機能とされています。このアプリでの自動取得・近距離探索は未対応です。[Appleの機能一覧](https://support.apple.com/ja-jp/126302)

地図はMapLibreとOpenStreetMap、航空写真は国土地理院の地理院タイルを使用します。国内の高解像度写真と、国外を含む低倍率の衛星画像で提供範囲が異なります。Apple Mapsではありません。[写真の提供範囲と出典](https://maps.gsi.go.jp/development/ichiran.html)

## データの扱い

広告・解析SDK・アプリ独自の中継サーバーはありません。保存を選んだメールアドレス・パスワードは、Android Keystoreの端末専用AES-256-GCM鍵で暗号化し、アプリ専用領域に保存します。確認コードは保存しません。認証済みセッションと追加連携設定は別々の鍵で暗号化します。バックアップと端末間転送は無効です。

保存をオフにして接続すると、既存の保存情報も削除します。「自分」→「Appleのログイン情報と自動ログイン」から保存情報を削除でき、サインアウトでも保存した認証情報を削除します。保存パスワードを画面に再表示せず、入力画面と自動認証画面のスクリーンショットは無効です。Apple側の追加確認やサービス変更により手動操作が必要になる場合があります。

Googleのアカウント選択と権限確認はGMSが行います。このアプリはGoogleのパスワード・確認コード・復号鍵を保存しません。権限要求だけで接続済みとは扱わず、取得できていない位置を表示しません。Googleの公式画面とCookieはAppleとは分離したアプリ専用WebViewプロファイルで維持します。「Googleアカウントの接続を解除」でローカルCookieと接続情報を消去できます。

ネイティブ画面の位置データとガラス描画用の地図画像はメモリ内で扱います。端末画像も公式の画像配信元から取得してメモリに保持し、この要求にアカウントのCookieや認証トークンを添付しません。Googleのサイト自身がWebViewプロファイルに保持するデータはGoogleの実装に依存します。追加連携で選択したファイルの管理は、そのファイルの所有者が行ってください。地図の表示範囲は地図提供元へ、Appleの更新要求はAppleへ、Googleの認証要求はGoogleへ送信されます。

Apple・Googleとは提携していません。各社のサービス変更によって使えなくなる場合があります。
